# Cafetería Inteligente Cat-fé 🐾☕

Sistema de gestión para la cafetería digital **Cat-fé**, desarrollado bajo arquitectura **MVC** con PHP 8+, MySQL, Bootstrap y JavaScript.

## Funcionalidades Principales
- Gestión de productos y menú.
- Control de mesas y pedidos en tiempo real.
- Registro de ventas y facturación.
- Control de inventario.
- **Módulo Innovador:** Análisis de productos más vendidos y control de desperdicios/mermas.

## Estructura del Proyecto
- `app/`: Lógica del sistema (Controladores, Modelos, Vistas y Configuración).
- `public/`: Recursos estáticos accesibles (CSS, JS, Imágenes).
- `database/`: Scripts SQL (`schema.sql`, `datos_prueba.sql`, `consultas.sql`).
- `docs/`: Documentación, requisitos y evidencias.
- `tests/`: Pruebas del sistema.
